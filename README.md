# bbs-ssa-reroll-tool
A tool to automate the process of getting a good supreme star amulet.

# Setup
Before setting up this program, you need to have both AutoHotkey v2 and Python set to your `PATH`.

Clone the repo into your PC.

Set the working directory into the root folder of the repo in your preferred way.
My favorite one is:
```sh
cd bbs-ssa-reroll-tool
```

Create a virtual environment using this command:
```sh
python -m venv .venv
```

Activate the virtual environment:
```sh
.\.venv\Scripts\activate
```

Install the dependecies with this following command:
```sh
python -m pip install -r requirements.txt
```

Then you can use `python main.py` to run the program.
